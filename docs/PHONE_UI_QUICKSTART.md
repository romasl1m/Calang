# 📱 Phone UI Quick Start Guide

## Instant Features Overview

### 🎯 Main Actions
```
┌─────────────────────────────────┐
│         Your Calendar           │
│                                 │

  [+]                        [☰]
```

### 🎮 Gestures

| Action | Gesture |
|--------|---------|
| 📅 Next week | Swipe left ← |
| 📅 Previous week | Swipe right → |
| ➕ New event | Tap green + |
| 📋 Open menu | Tap purple ☰ |
| 💻 Terminal | Tap ⌘ in toolbar |
| 📱 Event details | Tap any event |

### 🔘 Buttons

**Bottom Left (Green +)**
- Quick create new event
- Always visible
- Fastest way to add events

**Bottom Right (Purple ☰)**
- Open sidebar menu
- Access groups
- AI assistant
- Settings

**Toolbar (⌘)**
- Toggle terminal
- Run commands
- AI-powered
